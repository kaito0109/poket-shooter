# Pocket TPS（PUBG風バトルロイヤル試作）

Godot 4.6.3 / GDScript で作った、横持ちの3D TPS バトルロイヤル試作です。
飛行機からパラシュート降下し、島に落ちている武器やアイテムを拾い、縮小する安全地帯の中で最後の1人（CHICKEN DINNER!）を目指します。プレイヤー＋ボット24人の合計25人対戦。ブラウザでそのまま遊べます。

公開ページ: https://kaito0109.github.io/poket-shooter/

## 遊び方

- スタート後、飛行機が島の上を飛ぶ。好きなタイミングで Fキー（スマホは「降下！」ボタン）を押して降下
- パラシュート降下中は WASD で移動方向を調整（Wで加速、Sで減速）
- 武器は素手スタート。家の中や周辺に落ちている武器・弾薬・防具・回復アイテムを歩いて拾う
- 敵ボットも同じルールで降下し、武器を拾い、移動し、回復し、ゾーンを避ける。ボット同士も戦うので、キルフィードを見ているだけでも人数が減っていく
- ゾーン（青い円）が6段階で縮小。外にいると段階ごとに増えるダメージ
- 死んだ敵は武器やアイテムをその場に落とす

## 操作

- 移動: WASD / 矢印キー / 左スティック（タッチ）
- 視点: マウス（クリックでキャプチャ）/ 画面右側をドラッグ（タッチ）
- 射撃: 左クリック長押し / FIREボタン（タッチ）
- 狙う（ADS）: 右クリック長押し / 狙うボタン（タッチ）。Kar98Kはスコープ倍率が高い
- 武器切替: 1 / 2 キー / 武器ボタン。武器の持ち替え: Fキー（満杯のとき近くの武器と交換）
- リロード: R / RELOADボタン
- しゃがみ: C、リーン（覗き込み）: Q / E、一人称視点: V、ジャンプ: Space
- アイテム使用: 4 包帯 / 5 応急処置 / 6 医療キット / 7 ドリンク / 8 鎮痛剤
- 全体マップ: Mキー / マップボタン

## 武器とアイテム

- 武器5種: P92、マイクロUZI、M416、S686（ショットガン）、Kar98K（スナイパー）。弾は実弾（飛んでいく）で、距離で威力が落ちる。ヘッドショットは2倍ダメージ
- 弾薬は 9mm / 5.56mm / 7.62mm / 12ゲージ の4種類。武器ごとに使う弾が違う
- ヘルメットとベストは Lv1〜3。頭・体の被ダメージを減らす
- 包帯（少しずつ）、応急処置（HP75まで）、医療キット（全回復）、エナジードリンクと鎮痛剤（ブースト: 徐々に回復＋少し速く走れる）
- 回復アイテムの使用は被弾すると中断される

## 実装メモ

- マップは約480m四方の島。地形はノイズ生成の緩やかな起伏で、集落5つ（学校・港町・農場・住宅地・倉庫）と一軒家に家屋（ドア付き）がある
- プレイヤーモデルは CesiumMan（KhronosGroup glTF Sample Models、CC-BY 4.0）。リポジトリには含めず、CIビルド時にダウンロードしている
- 効果音は全てコード生成（音声ファイルなし）
